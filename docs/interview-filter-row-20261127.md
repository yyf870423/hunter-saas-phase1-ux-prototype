# 面试资料筛选行对齐

用户要求重新排列岗位面试资料页中面试轮次、有效状态所在的筛选行。旧布局给两个筛选外层分配150/140px，但实际按钮仅104px，导致外层与控件不齐、留白不均；清空按钮还单独占用外层第三列。

仅调整PositionInterviewMaterials的工具栏排版：搜索框在左，面试轮次和有效状态归为右侧同一组，两者等宽140px、等高40px，间隔8px；清空筛选移入同组并保持相同高度。手机宽度下搜索独占一行，两个筛选等宽并排，清空在下行。复用原有SearchField、SelectMenu、Button和现有色彩/边框/字体，不改公共控件样式。

没有改动搜索、筛选条件、默认值、记录数据、清空逻辑或下拉交互。AROS1420、后端、SDK及官网不改。

1440/871/390px三项Playwright检查通过：初始/已选状态控件尺寸、位置、间距、清空位置及无横向溢出均核对；技术一面与待核实组合得到原有一条记录，清空恢复8条，再搜索数据质量仍为原有一条记录。另1项面试指南整理、结果与历史版本回归通过。无脚本异常或网络写入，已核对真实截图与源码。
