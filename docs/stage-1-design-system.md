# 原型阶段一公共设计系统

> 状态：阶段一已通过人类审批并冻结。该文件只记录阶段一已经实际使用的 Token 和组件；后续阶段只能扩展，不能在业务页面中另起一套样式。

## 一、设计原则

2026-11-22拖线预览扩展（本地待验收）：公共`graphPathGeometry`供正式线及新建/改接虚线共用，`graph-connection-preview`统一自由端、目标端口及改起点方向。两类画布均按当前线形展示，无新增样式或节点避让，不改只读/保存合同，用户验收后推送。

2026-11-22端点改接扩展（本地待验收）：公共`GraphEdgeHandles`/`useGraphReconnect`供知识图谱与资产关系画布共用，选中线后显露两端拖柄，复用四侧`GraphNodePorts`完成同节点换面/跨节点改接，保持键盘、触摸、取消与只读边界。自然线仅按固定两端画平滑C段，用户最新取消节点避让，不保留A*及异形绕行。CSS同源，拖柄无位置过渡，缩小仍保持可点击尺寸；不新增单页样式或后台API。

2026-11-22图谱公共交互扩展（本地待验收）：`useGraphEdgePorts`统一普通拖动固定端口及新层级连接选点，`graph-presentation-storage`按作用域保存方向/线形；知识图谱和RelationshipCanvas共用，不单页实现。现有自动/手动布局保存沿用，readonly不写快照。详见`docs/graph-presentation-prototype-20261121.md`最新追加，尚未推送。

1. 采用 WorkBuddy 的持续工作区层级和 Vercel Geist 的清晰视觉语言，不复制任何单一产品页面。
2. 页面背景、内容表面和浮层形成三层深度；侧栏在浅色模式使用低对比冷白灰形成安静边界，在深色模式使用冷炭黑形成稳定识别区，两种主题使用不同明度但保持相同信息层级；亮蓝色只强调当前导航、主操作和需要注意的系统状态，不使用装饰性卡片墙和大面积渐变。
3. 业务优先级通过尺寸、位置、留白和边界表达，不依靠堆叠说明文字。
4. 默认亮色，深色模式保持相同信息层级；警告与风险允许使用黄色、橙色和红色。
5. 所有控件都有 normal、hover、focus-visible、active、disabled 和 loading 状态。

## 二、基础规格

| 类别     | 规格                                                          |
| -------- | ------------------------------------------------------------- |
| 正文     | 14px / 1.55                                                   |
| 辅助文字 | 12px 或 13px，不低于 12px                                     |
| 页面标题 | 24px，字重 650                                                |

## 三、产品级组件

2026-11-21本地原型：新增共享`GraphPresentationControls`（复用SelectMenu，预留的撤销入口复用IconButton/TooltipText）、`graph-presentation.js`（Dagre双侧自动布局、XYFlow圆角直角路径、坐标投影）及作用域样式。两类画布统一提供自然曲线/直角线、根节点居中的左/右及上/下双侧布局；用户要求先隐藏撤销布局入口，默认`showUndo=false`，不影响原有业务撤销。Icon使用lucide扩展曲线、直角、水平/垂直布局及撤销；SelectMenu仅新增可选`ariaLabel`，不改变已有调用。节点/关系详情文字不隐藏，画布关系标注仅悬停时出现。影响清单和只读边界见`graph-presentation-prototype-20261121.md`，待验收、不发布。

2026-11-22追加：公共`GraphNodePorts`覆盖可建关系节点，默认隐藏，hover显示四边中点圆点；20px交互区域、8px圆点，键盘/触屏可聚焦显示。两类画布使用共享四向端点/边界工具，世界坐标支持负值，显示原点补偿不改变保存坐标。节点与SVG几何层不使用位置/尺寸过渡；关系画布不随扩展拉长页面，节点hover不单独上浮。端口只是前端偏好，不能凭此新增后端能力，见`graph-presentation-prototype-20261121.md`追加章节。

2026-11-22鼠标中心缩放：公共`useGraphWheelZoom`与`graphZoomAtPoint`供两类画布复用，wheel锚定鼠标下的世界坐标，非被动监听阻止页面滚动。原生scroll量折算进pan，在绘制前归零，避免连续缩小时被滚动范围夹断；仅改变相机，不写节点或业务数据。保留工具栏命令、缩放步长和10%–150%范围。4条双端流程、48项锚点检查及12组算法对照通过，最新记录见round4第28号和`graph-presentation-prototype-20261121.md`。

2026-11-20已审批局部修复同步：公共`Icon`新增`maximize2 / minimize2`，直接复用lucide-react 0.468.0的`Maximize2 / Minimize2`，保持18px默认尺寸、1.8描边及既有无障碍规则。图谱全屏使用该图标对，自适应继续使用原四角框`maximize`，不得复用同一图形；工具提示复用`TooltipText`，不新增另一套SVG或控件样式。

1. `AppShell`：桌面导航、顶栏、移动顶栏和底部导航。
2. `SidebarNav`：核心工作导航、收起/展开和底部固定区；浅色主题使用冷白灰表面、深色文字与淡蓝选中态，深色主题使用冷炭黑表面、高对比浅色文字与蓝灰选中态；两种主题必须有明显明度差异，当前项和普通项均满足可读性要求。收起后使用固定 SVG 与无障碍名称，不显示系统原生 Tooltip。
3. `AssetNavigation`：桌面默认平铺公司、岗位、招聘机会、候选人、知识图谱，可在设置中配置显隐；`OtherAssetNavigation` 复用公共浮层从侧栏右侧展示未平铺项。数据管理在同级“数据工具”分组下，标题复用公共导航样式。移动端常用资产与其他共用配置，联系人仅从公司进入。范围见 `asset-navigation-preferences.md`。
4. `Topbar`：搜索、创建、主题和通知。
5. `Button` / `IconButton`：主、次、幽灵、危险和加载状态。
6. `StatusBadge`：运行、等待、异常、完成、观察和普通状态。
7. `SearchDialog`：搜索输入、最近访问、分组结果、无结果和键盘关闭。
8. `NotificationDrawer`：全部/未读、已读操作和空状态。
9. `Modal` / `Drawer`：统一尺寸、遮罩、焦点和关闭逻辑。
10. `Toast`：成功、信息、警告和错误。
11. 用量摘要：2026-09-07 起用户右拉菜单只显示已用百分比和到期日期，公共 Modal 保留相同两字段及订阅管理入口；取消侧栏用量环、任务次数和分项说明。
12. `DashboardSection`：2026-09-08 按用户授权改为任务焦点、洞察卡片与资产时间线。无外框标题含语义图标、实际数量与全量入口；标题区桌面最小 48px、手机 44px，分区与双栏间距 32px、手机 28px。页面分区没有卡片外框或阴影。
13. `TaskFocusBoard` / `TaskPlanMilestones` / `TaskProgressSummary`：任务焦点与可切换预览保留类型、名称、进度和状态，焦点补充原对象、摘要及真实计划节点。按待处理、待验收、推进、外部等待稳定排序，先排序再取最多 10 条；切换不改业务状态，独立箭头直接打开详情。复用公共按钮、状态与 Tooltip；任务标题桌面 22px、手机 20px，辅助字不小于 12px，切换项最小 88px。无计划不伪造节点。
14. `DashboardInsightCards` / `DashboardAssetTimeline` / `DashboardListSkeleton`：共用数据渲染，洞察单项卡片圆角 8px，资产变化使用图标时间线，不嵌套卡片。保留完整名称、类型、来源、时间、状态和说明；三区各最多 10 条，任务骨架对应焦点布局，公共 compact `EmptyState` 承载空态。详细响应式与状态入口见 `dashboard-layout-prototype.md`。
15. `ActionQueue`：默认收起的人工行动摘要。
16. `Skeleton` / `EmptyState` / `ErrorState` / `PermissionState`：全局状态组件。
17. `UserMenu`：显示当前用户和工作空间，并承载设置、切换工作空间和退出登录；支持外部点击与 `Escape` 关闭。
18. `AppTabs`：列表分类、详情分区和审核视图共用 WorkBuddy × Vercel 内容导航式 Tab；整行使用轻底边区分内容层级，选中项通过强调文字、字重和底部色条表达，计数使用弱底色徽标；业务页面不得另起一套按钮块或分段框 Tab。
19. `OverflowTooltip`：只服务于确实被截断的文本和 `+N` 隐藏标签；采用 WorkBuddy × Vercel 的中性高层浮层，亮色模式使用白色表面、细灰边界和短距离阴影，深色模式使用深灰表面，不使用箭头、左侧色带、彩色边框、毛玻璃、`title` 或 SVG `title`。鼠标悬停延迟约 `150ms`，键盘聚焦立即显示，移开、失焦或按 `Escape` 关闭；富信息改用 Context Card、Drawer 或详情页。
20. `TagList`：技能、行业、人物类别、论文主题和专利主题等同组标签统一使用 `8px` 横向间距和 `6px` 换行间距；隐藏项使用同行 `+N`，业务页面不得自行压缩标签间距。
21. `DatePicker`：日期、日期时间、出生年份、多年份筛选和月份区间共用同一个公共组件。每个字段只显示一个触发框；日期区间在同一浮层内依次选择开始与结束时间，开始与结束选择区始终左右排列，不上下堆叠。组件采用 WorkBuddy × Vercel 的中性表面、细边框、轻阴影和蓝色选中态，不显示浏览器原生日期、月份或时间控件。浮层打开时按 `Escape` 只关闭当前时间浮层，不连带关闭外层 Modal。
22. `AcademicPeopleList`：论文作者和专利发明人共用的紧凑人物名单。默认最多显示 5 位，论文作者必须直接显示论文署名机构；其余人物通过可滚动浮层查看，不在详情页继续堆叠大卡片。已关联姓名进入对应候选人，未关联姓名只打开该人物的单人身份审核 Modal；详情页不提供一次审核全部人物的入口。
23. `PersonIdentityReview`：单个人物的作者或发明人身份审核 Modal。系统每次只给出置信度最高的一位疑似候选人，不允许在审核 Modal 内搜索或更换候选人。短字段摘要只用于识别两侧人物，详细判断按联系方式、工作经历、教育经历、项目与研究经历分组；每组使用左右档案对照和一致性状态，不使用 Markdown 表格承载多条经历。两侧分别显示记录数量，数量不同时不按视觉行位强行配对；多出的记录保留在所属一侧，并以“来源未发现”“候选人补充”“来源未披露”等状态说明关系。桌面端左右对照，移动端在同一分组中按来源人物、疑似候选人的顺序纵向显示。关联候选人、保留人物线索和暂不关联使用三个独立按钮，点击即保存并更新当前人物状态，不再使用 Radio 后二次保存。
24. `SourceList`：资料来源和原始文件的统一列表。可访问的外部原文必须使用语义化链接并在新 Tab 打开；产品内详情使用按钮或路由跳转。所有可交互项都必须显示可点击指针和 hover 反馈。
25. `RelationshipCanvas`：人才版图和摸排批次共用的关系投影。固定提供视图切换、缩放、重置、节点选择和详情区；节点与关系的证据必须逐项打开当前任务快照，已关联业务资产可以进入对应详情。切换批次或投影时必须同步当前选中对象，不能保留上一视图的失效选择。
26. `MappingTargetList`：人才版图目标的公共清单。目标包含类别、优先级、完成标准、当前缺口、证据判断、下一步和状态；支持新增、查看、分区编辑、标记完成和重新打开。未知市场总人数不用于计算完成度，目标完成必须基于可理解、可行动和结果可预期的完成标准。
27. `SelectMenu` 图标型单选项：当选项本身对应固定 SVG 语义时，触发器和下拉选项统一显示“图标 + 文本”，图标位于文本左侧；图标只能辅助识别，文本仍是完整的可访问名称。知识图谱的节点类型使用该模式，节点图标由节点类型唯一决定，不提供独立图标配置。

## 四、复用约束

2026-09-07 新增 `AssetTypeNavigation`、知识图谱共享资料表单和导航类型偏好，见 `graph-types-navigation-prototype.md`；所有筛选控件统一文字 token 与普通 / 紧凑两档高度，见 `filter-controls-consistency.md`。两项为用户授权的后续原型迭代，待本轮验收，不改变其余已冻结设计。

1. 页面只组合公共组件和数据配置，不复制按钮、浮层、状态、列表行和导航实现。
2. 所有图标来自统一 SVG 映射；未知图标不能静默回退成无关图形。
3. 后续阶段发现组件不足时，先更新本文件和组件实现，再进入业务页面。
4. 组件的视觉状态和业务状态分离；同一个业务状态在工作台、详情和列表中使用相同颜色语义。
