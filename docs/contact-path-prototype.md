# 联系人联系路径原型决策记录

## 一、已确认边界

1. 联系人资产增加“联系路径”，用于整理猎头可以如何直接联系或通过关系引荐触达该联系人。
2. 联系人无论是否已经有手机号或邮箱，都可以按需创建或更新联系路径。直接联系方式是路径的一种，不替代其他关系路径。
3. 当招聘机会发现潜在联系人时，可以从招聘机会发起“寻找联系路径”；运行结果归属于联系人资产，招聘机会只显示联系人、路径摘要和入口，不复制关系数据。
4. Hunter 可以查找公开可验证的手机号或邮箱，也可以梳理同事、投资人、顾问和其他已有关系。新联系方式先作为待确认信息，用户确认后才写入联系人资料。
5. 联系路径只提供可执行建议和证据，不自动代表猎头联系任何人。

## 二、原型入口

- 联系人联系路径：`#/contacts/contact-chenyu?tab=contact-path`
- 尚未创建：`#/contacts/contact-chenyu?tab=contact-path&state=empty`
- 招聘机会触发入口：`#/opportunities/opportunity-xinglan`

## 三、交互要求

1. 联系人详情始终显示“联系路径”Tab，并在页头提供入口。
2. 未创建时，用户用自然语言说明优先关系、最大层数和排除条件；运行完成后展示关系图。
3. 已创建后支持继续用自然语言更新，并复用关系画布的平移、滚轮缩放、全屏、节点与连线详情、手动新增和编辑能力。
4. 招聘机会点击“寻找联系路径”后进入对应联系人，并自动打开创建或更新要求输入。
5. 图中每条路径展示关系名称、证据和最近核实时间；证据不足的结果不能伪装成已确认关系。
