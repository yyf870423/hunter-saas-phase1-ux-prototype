# 候选人联系路径：直接寻找

## 用户确认的变更

候选人详情的联系路径任务目标已明确，不需要用户额外填写提示词。按钮从“创建联系路径”改为“寻找联系路径”；点击直接运行，不再先弹出输入Modal。“更新联系路径”同样直接重新运行，不增加确认步骤。

## 实现边界

仅调整CandidatePages.jsx中的ContactPathTab，复用RelationshipAiEmptyState、RelationshipAiProcessingState和RelationshipCanvas。删除本页对RelationshipAiDialog及lastPrompt状态的依赖，不修改这些公共组件或CSS；其他联系人、公司关系等入口保持原流程。

空态显示“暂无联系路径”；点击后显示“正在寻找联系路径”、原有步骤和状态，完成后进入原有结果画布。同步移除要求用户说明关系层数等过时说明。保留“不自动联系任何人”的边界，不发送邮件、消息或新增权限。运行期间隐藏重复启动入口，并用运行中计时器防止同一时刻重复触发；离开页面清理计时器。

这是现有虚构数据的原型交互演示：仍使用原有2.4秒计时器，不代表已调用真实Agent或找到现实中的引荐关系。候选人结果图、证据、平移/缩放/布局行为及本机保存规则不改。AROS1420、SDK、后端和官网不在此次修改范围。

## 验证

5项Playwright检查通过：1440/871/390px分别覆盖空态、直接运行、结果和直接更新，无额外Modal或文本输入；快速重复点击只运行一次，离开页面清理计时器。另2项候选人画布回归通过，验证自然/直角连线、布局和无横向溢出。截图与源码对照沿用既有公共组件，布局扫描无发现；本轮不向后台写入数据。
