# 知识图谱原型交互覆盖矩阵

> 状态：本地原型实现中。本文件只约束原型覆盖，不替代产品详细设计。

## 一、验收原则

1. “摸排”是任务，“知识图谱”是正式业务资产；用户不需要理解底层共享关系层。
2. 顶层知识图谱只能由用户创建。导入和 Agent 只能在已有知识图谱中创建或更新图页。
3. 每个图页使用同一份节点、关系和资产引用数据，同时提供画布与层级表格两种展示方式。
4. 原型必须允许真实拖动节点、缩放、搜索、切页、展开收起、编辑、隐藏、恢复和审核，不以静态截图代替。
5. 关系型资产根据数据规模与用户判断任务选择关系图、层级图或可扩展表格，不强制用同一种图形承载全部关系。
6. 正式资产和已有可信关系变化后，引用它们的图谱与资产关系视图自动重算并刷新；只有证据不足、存在冲突或可能覆盖用户手工结构时才进入待确认。
7. 所有 AI 推断结果都通过固定组件显示；正式资产、来源业务关联和待确认分析层必须有不同状态。
8. 单个知识图谱同一时间只运行一个导入分析或 AI 整理任务，避免多个任务同时修改同一份图谱造成覆盖和审核混乱。

## 二、知识图谱核心页面

| 决策或能力       | 原型入口                                 | 必须可操作的内容                                                                                                             |
| ---------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 通用图谱资产列表 | `/mappings`                              | 搜索、打开、拖动时实时预览排序、放开后持久化顺序、菜单、删除、正常/空/错误状态                                               |
| 用户创建顶层图谱 | `/mappings/new`                          | 名称必填、说明可选；不能导入或让 Agent 直接创建顶层图谱                                                                      |
| 空图谱维护路径   | `/mappings/graph-empty`                  | 创建空白图页、导入图页、用自然语言让 AI 整理图页；AI 可提炼标题且标题可编辑                                                  |
| 多图页           | `/mappings/mapping-embodied?tab=content` | 新建、切换、重命名、删除图页；各图页独立保存布局和节点实例                                                                   |
| 画布与层级表格   | 同上                                     | 切换展示方式后仍选中同一节点，审核状态保持一致                                                                               |
| 画布交互         | 同上                                     | 拖动、框选或多选、批量移动、缩放、100%、自适应、聚焦、展开收起                                                               |
| 搜索与定位       | 同上                                     | 整图搜索，当前页优先；结果显示“图页名 + 节点名”，跨页定位、展开、居中和高亮                                                  |
| 节点操作         | 同上                                     | 新建自由节点、关联资产、编辑本地标题与备注、添加子节点、隐藏、删除后撤销                                                     |
| 关系操作         | 同上                                     | 新建与编辑本地关系、自定义连线显示名称、区分共享/来源派生/本地关系、查看证据摘要与原始网页、隐藏当前图页关系                 |
| 隐藏与多实例     | `?panel=hidden`                          | 普通搜索不显示隐藏节点；隐藏内容可恢复；同一资产可明确创建新实例                                                             |
| 导入图页         | `?panel=import`                          | 格式校验、结构预览、同名图页处理、默认开启智能分析、确认后图页先落地                                                         |
| 导入异常状态     | `?panel=import&case=unsupported` 等      | 不支持格式、文件损坏、多组彼此独立的结构和部分解析失败均有独立可验收状态；多组结构明确预览将创建的图页及不会被强行合并的结果 |
| 导入后台分析     | `?state=analyzing`                       | 进度、当前阶段、处理数量、暂停/继续、失败不回滚图页；再次发起时明确阻止                                                      |
| 分析失败与重试   | `?state=analysis-error`                  | 保留图页和已完成建议、重新分析、先查看已有建议                                                                               |
| 分析审核模式     | `?tab=reviews`                           | 待处理列表、图上/表格定位、上下文、资产对比、原始证据、确认并同步/修改/忽略                                                  |
| 标记生命周期     | `?tab=reviews`                           | 待确认持续显示；可信同步直接刷新，不额外展示“本次变化”标签                                                                   |
| 实时同步         | `?tab=content`                           | 正式资产、共享关系、来源业务关联变化直接更新；保留用户布局，新增节点局部放置                                                 |
| 排除和来源失效   | `?panel=hidden`                          | 用户删除形成图页排除；来源失效移除关系，保留有用户维护内容的节点                                                             |
| 版本与恢复       | `?tab=history`                           | 在页面内查看批次差异和当时图谱视图后再恢复，不使用 Modal；明确不会回滚正式资产或来源记录                                     |
| 图谱内 AI        | `?panel=ai`                              | 全屏资产内 AI 工作区、对话补充、计划、差异预览、审核写入；不进入任务列表                                                     |

## 四、必要状态

- 正常、加载、空、错误、无权限。
- 导入格式不支持、文件损坏、同名图页、多组独立顶层内容、多 Sheet、解析部分失败。
- 分析中、已暂停、待确认、冲突、处理失败、达到重试上限。
- 实时同步失败、来源失效、自动新增、用户排除、撤销与恢复；正常可信同步不额外打扰用户。
- 大图搜索无结果、跨图页命中、节点文字截断与自定义 Tooltip。

### 导入异常直达入口

- `?panel=import&case=unsupported`：文件格式不支持。
- `?panel=import&case=corrupt`：文件损坏或无法读取。
- `?panel=import&case=multi-root`：文件没有共同顶层结构，系统明确列出将分别创建的图页名称与内容范围；各图页保留原结构，不强行合并，用户之后仍可手动建立关系。
- `?panel=import&case=partial`：部分内容无法结构化时保留原文并待确认。
