## 已确认的产品规则

用户已同意并授权调整原型、直接推送 GitHub：

- 搜索字段：洞察标题、摘要、关联公司名称和关联人物名称。
- 来源名称、证据全文、任务聊天、类型和展示职位不作为独立命中字段；同一个词也在允许字段中出现时仍然命中。
- 沿用普通关键词子串匹配、去前后空白和英文不区分大小写，不新增语义扩展、正则或高级查询语法。
- 保留已确认的选择联动：当前项匹配则保留，不匹配选首条，无结果清空详情；回退成为当前选择，清空条件不恢复旧项。

## 代码映射

- `src/stage2/signal-search.js`：明确的搜索字段白名单；不对整个洞察对象序列化后搜索。
- `src/stage2/data.js`：8 条现有原型洞察补充 `relatedNames`，只明确已有公司/人物名称，不改展示内容；避免从夹有职位的 `object` 字符串中拆猜名字。
- `src/stage2/Signals.jsx`：复用搜索匹配函数与原有筛选、排序、选择、公共搜索控件及空态，不改样式。
- `tests/unit/signal-search.test.js`：8 项字段边界与输入回归。
- `tests/stage2/insight-search.spec.js`：4 项浏览器交互回归，结合已有 6 项选择联动回归。

`relatedNames` 是原型样例的结构化关联名称，不要求生产 API 照搬该字段名。后续产品对接应从有权限的真实关联对象取得名称；不能从演示数据补真实资料。
