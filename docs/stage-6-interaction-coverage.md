# 原型阶段六运营端交互覆盖清单

> 状态：自动化测试通过，等待产品负责人审批。

## 一、运营概况

| 操作或状态       | 入口                   | 覆盖结果                        |
| ---------------- | ---------------------- | ------------------------------- |
| 查看趋势和下钻   | `#/ops/overview`       | 指标进入对应明细并保留时间口径  |
| 切换快捷时间范围 | 页面右上角             | 近 24 小时、7 天、30 天、自定义 |
| 自定义时间       | 选择“自定义”           | 显示统一时间选择器              |
| 局部数据失败     | `?state=partial-error` | 其他指标继续可用，可单独重试    |
| 加载与整体错误   | `?state=loading/error` | 显示统一状态和重试入口          |

## 二、用户与工作空间

| 操作或状态         | 入口                      | 覆盖结果                                               |
| ------------------ | ------------------------- | ------------------------------------------------------ |
| 搜索与筛选工作空间 | 工作空间 Tab              | 列表真实变化，筛选可单独清空                           |
| 查看工作空间详情   | 点击工作空间              | 查看账号、订阅、用量、任务、存储和支持引用             |
| 查看用户账号       | 用户账号 Tab              | 查看身份、安全、会话摘要和工作空间关系                 |
| 处理试用申请       | 试用申请 Tab              | 批准、暂缓、拒绝，包含必填校验、标准结果说明和执行反馈 |
| 无待处理申请       | `?tab=trials&state=empty` | 显示空状态                                             |

## 三、订阅与额度

| 操作或状态               | 入口                        | 覆盖结果                                   |
| ------------------------ | --------------------------- | ------------------------------------------ |
| 查看订阅、订单和调整记录 | 三个 Tab                    | 使用同一工作空间与权益数据                 |
| 支付异常                 | `?tab=orders&status=failed` | 说明宽限期和自动化权益影响                 |
| 调整权益                 | 点击订阅工作空间            | 必须填写原因，显示调整前后值并生成审计反馈 |

## 四、任务与故障

| 操作或状态         | 入口                 | 覆盖结果                                                 |
| ------------------ | -------------------- | -------------------------------------------------------- |
| 搜索和多选筛选任务 | `#/ops/tasks`        | 任务列表真实变化并支持清空                               |
| 查看错误聚合       | `?tab=errors`        | 错误分类、影响范围、代表任务和处理进展                   |
| 查看脱敏任务详情   | `/ops/tasks/:taskId` | 状态、时间线、调用链、能力、资源和关联记录               |
| 安全恢复           | `TASK-260824-019`    | 从检查点继续、重新入队、释放资源、重新分配资源、退还额度 |
| 不可安全恢复       | `TASK-260824-018`    | 不显示恢复动作，并明确原因                               |
| 任务详情加载       | `?state=loading`     | 显示统一加载状态                                         |

## 五、系统能力

| 操作或状态       | 入口                     | 覆盖结果                                       |
| ---------------- | ------------------------ | ---------------------------------------------- |
| 查看服务健康     | `#/ops/capabilities`     | 能力、成功率、延迟、容量、成本、降级和影响范围 |
| 查看降级详情     | `?capability=cap-search` | 显示路由、事件和影响范围，可关联或创建安全事件 |
| 编辑配置草稿     | `?tab=configuration`     | 编辑不影响当前有效版本                         |
| 验证失败         | 配置 Modal 的失败示例    | 当前版本继续生效，显示逐项失败原因             |
| 验证成功并切换   | 配置 Modal               | 二次确认后创建新版本并记录审计                 |
| 运营人员权限受限 | 切换运营人员角色         | 可看状态，不能编辑高风险配置                   |
