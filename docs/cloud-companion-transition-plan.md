# 云端与外部简历工具边界调整

> 状态：2026-08-30 经产品负责人确认，替代此前“云端与配套寻访 App 协作”的全部方案。

## 一、决策结论

Hunter 云端产品不与任何自动访问认证人才平台的本地 App、浏览器插件或其他工具建立通信、任务下发、状态同步、结果回传或设备授权关系。

用户可以在系统外使用独立工具整理简历，也可以从其他合法来源获得简历文件；但文件进入 Hunter 的唯一方式是**用户主动上传**。Hunter 不判断、控制或追踪外部工具如何运行，也不在产品中提供外部工具的下载、连接、设备管理和运行状态。

## 二、Hunter 云端允许的能力

1. 检索和整理无需登录即可访问的公开网络信息。
2. 使用系统已有候选人、人才版图、论文、专利和开源项目资料寻找人物线索。
3. 接收用户主动上传的 PDF、DOCX、图片或批量压缩包等简历资料。
4. 对上传资料执行文件类型门禁、解析、人物身份判断、查重、字段合并、资料补全和人岗匹配。
5. 上传内容与系统资产存在冲突时，向用户展示来源和字段差异，再按审核或已配置的自动授权写入。
6. 保留用户上传文件、解析结果、来源说明和写入记录，支持后续查看与追溯。

## 三、Hunter 云端禁止的能力

1. 登录、自动操作或控制猎聘、脉脉、BOSS 直聘、LinkedIn 等需要认证的人才平台。
2. 向本地 App 或插件发送岗位、筛选条件、任务包或自动化指令。
3. 接收本地 App 或插件的实时结果回传、运行心跳、登录状态和错误状态。
4. 展示“在本机继续”“选择设备”“下载任务”“等待本机结果”等跨端协作交互。
5. 在设置中管理本地设备、连接码、插件授权、版本或同步状态。
6. 将外部工具描述为 Hunter 官方配套能力，或通过云端入口引导用户安装、启动和操作该工具。

## 四、产品流程

1. Hunter 从系统资产和公开来源开始处理任务。
2. 用户可以在任意时点通过任务对话或业务资产上传补充简历。
3. 上传文件作为一条明确的用户输入出现在对话和来源记录中。
4. Hunter 对每批上传资料执行身份判断、查重、合并、资料更新和最新岗位匹配。
5. 新增候选人、已有候选人更新和身份冲突分别进入对应审核路径。
6. 处理完成后，任务继续使用统一候选人审核和岗位推进逻辑，不区分资料由哪种外部工具整理。

## 五、原型调整范围

| 区域         | 删除内容                                                 | 保留或新增内容                                   |
| ------------ | -------------------------------------------------------- | ------------------------------------------------ |
| 工作台       | 本机协作异常、独立执行摘要                               | 重点任务、信号和行动队列；公开来源局部失败       |
| 岗位招聘任务 | 本机任务准备、设备选择、任务包下载、本机等待和旧任务回传 | 公开检索、用户上传简历批次、统一合并和候选人审核 |
| 候选人       | 本机结果回传来源                                         | 用户上传简历、来源说明、身份合并和字段变化审核   |
| 设置         | 寻访 App 设备、连接码、设备版本和同步状态                | 个人发件邮箱及协议探测                           |
| Landing Page | 配套工具回传、人才平台结果回传                           | 用户主动上传简历并统一查重与匹配                 |
| 通知         | 设备授权、结果提交和版本异常                             | 简历导入完成、资料变化和审核提醒                 |

## 六、验收标准

1. 用户可见页面和当前产品文档不再出现本地 App 通信、设备连接、任务下发和结果回传能力。
2. 岗位任务能够显示用户上传简历的文件、时间、批次数量和处理结果。
3. 用户上传简历与系统候选人疑似同人时，仍能查看完整差异并决定是否合并。
4. 公开来源失败只影响对应来源，不删除已有结果，也不引导用户转到本地工具继续。
5. 设置中心只保留个人发件邮箱连接，不出现本地设备管理。
6. 自动化测试覆盖上传批次、来源失败、身份冲突和新简历回流。

## 七、外部工具边界

独立简历摘取 App 或插件不属于当前 Hunter 云端产品，也不进入本轮原型和详细设计。未来如单独评估该工具，应独立进行合规、产品价值、分发方式和数据安全论证，不能默认恢复与 Hunter 云端的通信关系。
