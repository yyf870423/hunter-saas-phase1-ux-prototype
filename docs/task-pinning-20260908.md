# 任务置顶交互补齐

日期：2026-09-08。用户要求快速补齐任务列表已有置顶标志对应的样式和交互。已阅读实际 `WorkHistory`、任务数据、公共控件和当前截图，现有列表可以承载，不重新设计任务工作区。

## 交互约定

1. 复用公共图钉图标按钮和 Tooltip，置顶蓝色常显，未置顶在悬停/聚焦时显示，触屏常显。提示明确为“置顶任务”或“取消置顶”。
2. 按钮不触发任务打开，不修改当前选中任务、草稿或执行状态；立即更新标记和排序，无确认弹窗。
3. 已置顶组排在前面，同组保持原输入顺序；取消后恢复到原有未置顶顺序。搜索和归档仍先限定范围，不把范围外任务带回列表。
4. 以任务稳定 ID 在浏览器保存偏好，刷新、切换详情和同源页面共享。可以取消示例默认置顶，存储失败时不改变界面状态并用公共 Toast 提示重试。
5. 窄屏通过公共 Drawer 打开任务列表，共用相同列表和操作。桌面收起栏按相同置顶顺序显示。
6. 本轮仅补独立原型任务历史，不改变工作台已确认的待处理、待验收、推进、等待外部优先级，不修改正式 Hunter 产品。

## 组件与验收

`TaskHistoryList` / `TaskPinButton` 复用 `IconButton`、`TooltipText`、`StatusBadge`、`EmptyState`，共享偏好在 `task-pin-store.js`，列表布局沿用 `WorkHistory` 与公共 Drawer。覆盖置顶/取消、默认置顶取消、刷新、同源同步、搜索、归档、动态任务、存储失败、空态、键盘和桌面/手机明暗截图后交付。
