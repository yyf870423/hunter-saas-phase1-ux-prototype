# 阶段七：首页与认证 Moodboard 交互覆盖

> 状态：三套 Moodboard 已实现，等待人类选择设计方向。完整首页信息架构尚未冻结。

## 一、页面入口

| 内容       | 编排中枢                                        | 智能图谱                                | 人才观测站                                    |
| ---------- | ----------------------------------------------- | --------------------------------------- | --------------------------------------------- |
| 首页       | `#/moodboards/orchestration`                    | `#/moodboards/graph`                    | `#/moodboards/observatory`                    |
| 用户登录   | `#/moodboards/orchestration/auth`               | `#/moodboards/graph/auth`               | `#/moodboards/observatory/auth`               |
| 用户注册   | `#/moodboards/orchestration/auth?mode=register` | `#/moodboards/graph/auth?mode=register` | `#/moodboards/observatory/auth?mode=register` |
| 运营端登录 | `#/moodboards/orchestration/ops-login`          | `#/moodboards/graph/ops-login`          | `#/moodboards/observatory/ops-login`          |

总入口：`#/moodboards`。

## 二、交互覆盖

| 操作       | 正常路径                                             | 异常或边界状态                                    | 覆盖状态 |
| ---------- | ---------------------------------------------------- | ------------------------------------------------- | -------- |
| 首页导航   | 锚点进入工作方式和业务成果；进入登录、注册及设计方向 | iPhone 使用独立移动菜单；外部点击不依赖原生菜单   | 已覆盖   |
| 3D 场景    | 鼠标移动产生轻量视差；场景持续运行                   | 移动端降低镜头影响；`reduced-motion` 停止自动动画 | 已覆盖   |
| 编排流程   | 切换理解目标、探索证据、人工审核和沉淀成果           | 当前步骤始终只有一个，说明和计划预览同步变化      | 已覆盖   |
| 图谱流程   | 切换公司、人物、研究成果和证据投影                   | 未选中内容不显示虚假详情                          | 已覆盖   |
| 观测流程   | 选择信号并查看核验信息、影响和关联资产               | 中高优先级使用不同语义，不使用装饰性警示色        | 已覆盖   |
| 用户登录   | 输入账号和密码，完成后进入成功状态                   | 必填、密码长度、凭据错误、加载和禁用              | 已覆盖   |
| 用户注册   | 输入姓名、账号、验证码和密码，提交申请               | 必填、验证码未输入、密码过短和处理中              | 已覆盖   |
| 密码显示   | 使用 SVG 按钮显示或隐藏密码                          | 键盘聚焦和禁用状态                                | 已覆盖   |
| 运营端登录 | 账号密码通过后进入二次验证                           | 账号停用、必填缺失、验证码错误                    | 已覆盖   |
| 响应式     | 桌面、iPad 和 iPhone 显示同一品牌方向                | 不产生横向溢出；认证页移动端移除高负载视觉区      | 已覆盖   |

## 三、视觉和自动化门禁

1. 三个首页 Canvas 均通过 WebGL 像素检查，避免只有空白 Canvas。
2. `1440 × 900` 已检查首页首屏、流程区和认证页。
3. `820 × 1180` 和 `390 × 844` 已检查内容溢出。
4. 注册校验、成功反馈、运营端二次验证均有 E2E 用例。
5. 全仓库加入本阶段用例后共 `172` 项 E2E，前六阶段 `161` 项既有用例和阶段七 `11` 项专项用例均已通过。

## 四、尚未进入本轮的内容

2. 正式注册资格、账号验证渠道和隐私协议内容。
