# 工作台首页与人才地图标签

日期：2026-09-08。范围：独立 SaaS 原型，用户授权直接推送并同步详细设计；不修改 Hunter 正式产品。

## 交付内容

- 工作台从三组连续列表改为任务焦点与可切换预览、洞察卡片和资产时间线。原任务状态、计划步数、当前步骤、洞察来源/状态/下一步、资产变化/时间/详情入口全部保留。
- 默认 5/8/10、各区最多 10 条及任务处理优先级不变；焦点只提供预览，不创建第二份任务状态。手机切换后回到当前预览，独立箭头直接进入详情。
- 任务列表中的“公司组织梳理 · 知识图谱”改为“公司组织梳理 · 人才地图”，通用知识图谱资产名称、类型和路由不变。
- 公共组件、页面布局、交互覆盖和详细设计 02、10 同步更新；原型截图见 `docs/assets/dashboard-home-20260908/`。

## 验证

1. 64 项相关页面 E2E 通过：任务预览与所有详情跳转、键盘选择、手机预览定位与 Tooltip、新任务成功/存储失败、行动队列、三类局部空态、加载、错误重试、受限、容量、明暗主题和公司组织标签。
2. 另有 15 项机会生命周期回归通过，包括动态任务、机会跟进、通知、无任务工作台、岗位资料和候选人审核联动；38 项领域单元测试通过。
3. 构建通过；保留项目原有的大 chunk 提示，不在本轮扩展为全站打包优化。
4. 已对比改前与改后真实截图，覆盖 1440px 桌面、820px 平板、390px 手机、明暗主题及异常状态；修复首屏任务区过高、辅助字号与公共规格不一致、手机切换后预览不可见的问题。无页面横向溢出，无新增控制台错误。
5. 最终复核与文档记录由当前会话执行，未使用独立复核代理。布局扫描发现的选中侧边色条已移除；字体/圆角提示源于仅描述营销页的根设计文件，本页沿用操作界面的公共规格，不改写营销设计。
