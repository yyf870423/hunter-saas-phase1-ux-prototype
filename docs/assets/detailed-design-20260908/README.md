# 2026-09-08 详细设计原型配图

18 张截图来自已部署的 GitHub Pages 原型，应用代码基线为 `c44494f`。配图覆盖单资产对话确认、保留的候选人批量确认、任务类型、岗位输入和形成、机会资料与跟进、通知、全局新建及订阅用量。

`manifest.json` 记录页面路由、所属章节、原始尺寸和 SHA256。画面中的业务资料均为原型演示数据；打开对应路由后，部分状态需要通过页面操作触发，不代表路由本身会重放截图状态。

本目录只包含公开原型资源，不包含在线文档备份、账号信息、上传凭据或同步日志。截图与已同步详细设计使用相同源文件；本轮不重复全量测试，原型与生产能力的边界见 [业务与验收说明](../../opportunity-lifecycle-prototype.md)。
