# 任务后续对话边界检查

日期：2026-09-08。状态：本轮实现与相关回归完成，用户已授权直接推送原型、同步详细设计。本文件记录回复后续阶段的检查，不代表整个产品已完成正式开发。

## 本轮边界

- 普通分析、证据、少量结果、持续跟进摘要、等待、暂停、错误说明使用公共 `HunterReply` / `HunterMarkdown`。
- 单个资产新增或修改、单项跟进安排及其修改或取消、单个周期计划确认使用 Markdown 展示实际内容，回复是、否或修改建议；建议只更新待确认内容，不能直接执行。
- 链接只查看或导航，不承担写入、取消安排或发送。实际状态、授权、版本、时间、去重与归属继续由业务代码校验。
- 岗位找人、批量候选人及联系人审核、身份冲突、多个图谱的保存范围、邮件收件人与正文审核、文件预览、执行计划和授权模式继续使用既有专用组件。
- 资产详情页手工跟进记录、日期选择和编辑表单不变；只替换任务对话里复用的详情卡片，不全局修改 `OpportunityFollowupSummary`。

## 源码发现

| 任务范围 | 后续状态 | 处理 |
| --- | --- | --- |
| 客户开发、资料形成机会 | 确认机会后、邮件回复更新后、已有或已删除来源的任务安排 | `TaskOpportunityFollowup` 不再复用资产详情表单；摘要与确认进入对话，保留真实任务归属 |
| 新建与修改周期任务 | 周期方案已经形成，用户补充修改或确认 | 单项方案确认改为 Markdown；多目标澄清仍保留互斥选择 |
| 岗位招聘 | 停止、权限受限、错误、邮件等待、收到新简历后 | 普通信息使用 Markdown，批量写入、身份冲突和邮件审核保留 |
| 人才摸排 | 批量审核完成、保存范围选择、后续补充、失败恢复 | 普通信息使用 Markdown；多图谱保存范围不简化为单项确认 |
| 候选人求职 | 人工联系后等待、收到新简历、追加要求、错误恢复 | 普通信息使用 Markdown；岗位匹配和查看完整资料保留 |
| 周期运行 | 等待身份判断、决定后继续、补充文件、停止 | 普通信息使用 Markdown；多项身份冲突保留专用选择 |
| 岗位创建、独立身份核验、沟通摘要、推荐报告 | 首次结果与连续补充后的输出 | 检查共享任务对话、Markdown 和文件组件，不重做资产专业工作区 |

## 验证门禁

1. 先截图现有后续状态，不能只检查初次机会确认页。
2. 通过真实 UI 完成客户回复、机会更新确认、跟进建议、修改、否定、肯定及再次补充；检查取消、缺失时间、非法时间、权限、版本和重复确认。
3. 对其他任务实际触发审核后、联系后、收到回复后、追加要求和停止恢复状态，记录逐项结果。
4. 桌面与手机成组截图，核对没有对话专用卡片残留或横向溢出；专用资产交互仍可完成。
5. 仅运行本轮相关的定向回归，不重复整个原型的全量测试。完成后推送 GitHub 并同步相关在线设计与配图，保留既有文档表格宽度、画板和无关内容。

## 实现与验证结果

- 7 类任务范围均完成源码检查；客户回复、岗位候选人回复、求职回复、摸排追加、独立核验、摘要、推荐报告和周期运行均由浏览器实际触发后续输入。
- 跟进安排、修改、记录、取消、拒绝、建议、实际时间及未来时间、附件追加、重复确认、刷新恢复、仅分析、权限、来源归属、版本变化及来源删除经过定向回归。附件与“是”一起提交时只更新草稿，仍需再次确认。
- 修复客户回复后的会话顺序和自动滚动，最新跟进位于旧审核消息之后；机会入库/暂缓与继续核实联系人分阶段提问，避免一个答复同时确认两个动作。
- 独立核验、摘要和推荐报告保留用户实际输入，不再把固定示例冒充用户的后续回复；推荐报告预置修订文件显式标明原型能力边界。
- 周期计划的建议保留原目标，确认后列表读取实际目标及周期；当前仅在浏览器会话保存配置，不接入真实调度器。
- 相关 68 条 Playwright 用例分批通过；25 条领域和解析单元测试通过；生产构建通过。未重复全原型的全量测试。构建仍有原有的大包体积提示，本轮未做无关拆包。
- 桌面与手机截图确认 Markdown 摘要、确认问题、输入区及结果没有横向溢出；资产详情手工表单、候选人批量审核、联系人审核、邮件草稿及周期身份冲突继续可用。

### 公共组件映射

`TaskOpportunityFollowup` 与 `SingleAssetTaskSummary` 使用 `HunterReply`；跟进命令与 `singleAssetDecision`、`nextFollowupDraft`、既有领域命令协作，样式不另建。`OpportunityFollowupSummary` 及编辑器仅保留给资产详情手工操作。周期草稿也复用原有输入区和 Markdown。
