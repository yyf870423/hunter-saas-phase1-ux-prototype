# 全原型筛选控件一致性

日期：2026-09-07。用户追加要求：知识图谱筛选框的高度、字体和样式不一致，需要一并处理所有原型页面的同类问题。本轮覆盖当前 SaaS 原型用户端与运营端，不回写历史废弃原型或 Hunter 正式前端。

## 现状与统一规格

原型公共搜索框为 40px / 13px 常规字重，选择器为 36px / 12px 加粗；行业触发项存在继承正文 16px 的情况，运营后台另有 38px / 12px 的搜索框实现。相同筛选行因此出现高度、字重和边框来源差异。

- 公共文字 token：`--s1-control-font-size: 13px`、`--s1-control-font-weight: 400`、`--s1-control-line-height: 20px`。
- 普通筛选：`.s4-filter-scope` 提供 `--s1-field-height: 40px`，搜索、选择、日期、行业、收藏夹、数字组合框和列设置入口继承同一高度。
- 详情内紧凑表格：`.s4-filter-scope.is-compact` 为 36px，保持紧凑工具区，同一行搜索与下拉不再混用 34px / 36px。
- 筛选项不压缩到小于其触发框，空间不足时按公共布局换行；窄屏行内滚动不能造成相邻下拉、输入和数字组合框重叠。自动化除页面溢出外，也检查控件与占位宽度。
- 表单与画布工具栏不自动继承列表高度；选择文字与输入文字使用相同字体规格。
- 边框、底色、圆角和阴影继续使用现有主题 token；选中项通过颜色与勾选区分，不靠额外加粗。
- `OpsFilterBar` 改为复用 `SearchField`，保留后台布局和清空筛选交互，删除重复的搜索控件 CSS。
- `SelectMenu`、`DatePicker`、行业和收藏夹浮层挂载在所属应用容器内，保持主题；选择器 Escape 只关闭当前浮层并恢复焦点，不连带关闭外层编辑窗口。
