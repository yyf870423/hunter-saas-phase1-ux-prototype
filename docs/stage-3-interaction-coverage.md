## 验收状态 URL

每条主线至少交付以下可直接访问状态：

1. 正常渐进路径。
2. `state=loading`。
3. `state=stream-error`。
4. `state=limited`。
5. `state=waiting`。
6. `state=error`。
7. 该类主线至少两个专用业务分支。

无法通过 URL 独立进入的交互必须在最终验收清单中提供入口和操作步骤，包括审核、授权、补充文件、计划调整、等待恢复、终止和删除。

专用业务空结果分别使用客户开发 `state=no-contact`、岗位招聘 `state=no-candidate`、人才摸排 `state=gaps` 和候选人求职 `state=no-position` 表达，不使用与业务无关的统一空白占位。

人才摸排审核新增以下交互覆盖：

1. 默认进入关系画布，并可切换组织与方向、公司生态、方向与角色、人物关系、人才流动、联系路径和学术脉络七种视图。
2. 点击节点查看对象事实、证据和直接关系；点击连线查看方向、时间、状态和证据。
3. 画布支持放大、缩小和重置，画布内部滚动不造成页面横向溢出。
4. 待确认人物或关系可以从画布确认写入，并与人物明细、冲突与待补充标签页保持同一状态。
5. 移动端将关系画布与详情上下排列，画布在自身区域内浏览，详情字段和证据仍可完整查看。
