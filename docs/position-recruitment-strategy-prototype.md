# 岗位招聘难度与找人建议原型决策

## 目标

岗位 Agent 在解析岗位时，同时判断招聘难度，并给出可以直接执行的找人步骤。用户不需要先理解应该从招聘网站、已有候选人、公开网络还是人才摸排开始。

## 已确认口径

1. 该能力属于岗位资产内的 AI 解析，不新增独立任务，也不增加新的一级页面。
2. 分析结果包括招聘难度、判断依据和有顺序的找人建议。
3. 建议会根据岗位变化而不同：低难度岗位可以优先从已有候选人和招聘网站开始；高难度岗位需要更早使用人才摸排、公开网络、论文专利和关系探索。
4. Hunter 只给出分析和建议，不因分析完成而自动启动找人、人才摸排或外部平台操作。
5. 用户审核后，结果保存在岗位资料中；该结果不提供手动编辑入口，需要调整时重新运行岗位 AI 解析并在审核页选择是否应用。
6. 云端产品不自动操作需要登录的招聘网站。步骤中提到招聘网站时，明确由猎头筛选并把简历上传到 Hunter。
7. “建议挖猎的公司”与招聘难度放在同一个“招聘分析”视图中。每家公司展示目标团队、机会信号、建议优先级和依据，用户可以查看依据，但不能直接把推断改写成确定事实。

## 原型入口

- 岗位信息：`#/positions/position-vla?tab=profile`
- 招聘分析：`#/positions/position-vla?tab=profile&profile=analysis`
- 重新分析：在岗位资料的“当前岗位 JD”或“招聘难度与找人建议”中点击 `AI 解析` / `重新分析`
- 结果审核：`#/positions/position-vla?tab=profile&ai=review&panel=review`

## 当前岗位示例

“具身智能 VLA 算法负责人”被判断为高难度岗位。建议先复用已有候选人完成人岗匹配，同时由猎头在招聘网站定向筛选；随后使用公开网络、论文专利补充人物线索，并将目标公司组织结构与关键人纳入人才摸排。该建议说明先后顺序和每一步的产出，但不会自动执行。
