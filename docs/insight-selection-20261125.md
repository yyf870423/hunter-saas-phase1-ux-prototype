# 洞察中心：筛选与详情联动

日期：2026-11-25。基线：main `5305c114f1e5469b8859c7698526e57607fe4169`。

## 已确认规则

用户已批准本次修复并授权验证后直接推送 GitHub，不需要再次等待验收。

1. 搜索或切换筛选后，当前洞察仍在结果中则保留。
2. 当前洞察不在结果中，则选第一条匹配结果。
3. 无匹配结果时，右侧显示空态，不继续显示旧详情、证据或处理按钮。
4. 回退结果成为当前选择；清空搜索、返回“全部”后，不复活已被过滤掉的旧选择。
5. 用户可以继续点击其他结果；新的有效 `signal` 定位继续支持。筛选直接取 URL 值，避免旧筛选状态与新 URL 不一致。

## 实现范围

- `src/stage2/Signals.jsx`：选择只从可见结果解析；记录当前选择与已消费的 URL 定位，保留后续选择；无结果复用公共 `EmptyState`。切换选择关闭旧证据弹窗，空态不渲染旧证据。
- `tests/stage2/insight-selection.spec.js`：新增 6 项选择联动回归。
- `tests/stage2/tasks-signals.spec.js`：更新“取消忽略”的旧预期；离开“已忽略”结果集时先回退，返回“全部”保持回退，再主动选择原条目。
- 不改业务文案、处理写入规则、Agent、接口、官网或其他页面。
