# 资产导航平铺与偏好配置

日期：2026-09-07。范围：独立 SaaS 本地 UX 原型，未进入 Hunter 正式代码、在线详细设计或部署。

## 用户已确认的需求

- 常用资产导航不再通过向右展开的资产抽屉进入，改为平铺。
- 默认顺序：公司、岗位、招聘机会、候选人、知识图谱。
- 用户可以在设置中配置平铺显示的资产导航。
- 未平铺显示的导航统一放入“其他”，沿用相近的选择交互，仍能访问。
- 后续确认：“其他”从侧栏右侧展开；数据管理增加与“业务资产”同级的上级导航标签，使用“数据工具”。

## 现状与本轮取舍

- 已阅读 `Stage1Shell.jsx`、导航数据、公共浮层和设置页代码；现有桌面端“业务资产”入口向右打开全资产面板，不能承载直接平铺需求。设置页没有导航偏好。
- 保留现有导航宽度、收起/展开、核心业务、数据管理、用户菜单、字体和色彩。仅替换资产导航部分，不重新设计资产详情。
- 本轮配置显隐，不增加自定义排序；统一按公司、岗位、招聘机会、候选人、知识图谱、论文、专利排列。允许全部平铺或全部放入“其他”。全部平铺时不显示空的“其他”入口。
- 设置入口为“设置 > 导航”，复用设置公共布局、行、开关和保存按钮；恢复默认先更新草稿，保存后应用。离开或刷新时未保存的草稿丢弃，不改变当前导航。
- 移动端保留既有底部“业务资产”入口，第一层显示配置的常用项和“其他”，第二层仅显示剩余资产；与桌面使用同一份配置。不是把七个资产塞入底部主导航。
- 联系人是公司子资产，不恢复独立导航。数据管理不是本轮可配置的资产类型。
- 原型偏好仅保存在当前浏览器，不读取或发送真实账户数据；正式跨设备偏好同步不在本轮实现范围。

## 公共组件与边界

后续知识图谱增加可配置快捷类型，导航偏好仍使用同一个存储对象共同保存；侧栏密度和用户菜单用量摘要同步调整，见 `graph-types-navigation-prototype.md`。本页其余资产显隐规则不变。

- `asset-navigation-store.js`：从现有资产清单派生固定顺序的选项；校验版本、允许 ID、重复值和损坏数据，合法空列表不回退默认。保存失败不覆盖当前导航；刷新和同源多页同步。
- `AssetNavigation.jsx`：桌面“其他”浮层和移动资产选择共用资产项渲染；复用 `Icon`、`IconButton`、`Drawer`、`FloatingPanel` 及既有导航样式。
- `NavigationSettingsPage`：组合 `SettingsPageHeader`、`SettingsSection`、`SettingRow`、`Toggle`、`Button`、`InlineNotice`。支持正常、未修改禁用、加载、读取失败、保存失败、权限受限、全部关闭及恢复默认。
- `FloatingPanel` 增加可选 portal 容器、`placement="right"` 和 `gap`，默认上下定位行为不变；导航浮层挂载到当前应用根节点，保持深色主题上下文。侧向浮层按实际高度限制视口边界，跟随滚动和尺寸变化，不写死导航行坐标。
- 数据管理所属区域复用 `.s1-nav-section h2` 增加“数据工具”分组标题，不新增入口，不改变移动端导航。
- 不新增视觉 token，不复制业务页面样式；关闭“其他”、按 Escape、点击外部和选择后关闭已验证。收起后的图标复用 `TooltipText` 显示隐藏标签；公共设置页操作区补齐窄屏多按钮等宽布局。

## 交互覆盖（已通过）

| 入口         | 正常路径                                     | 异常 / 边界                                      |
| ------------ | -------------------------------------------- | ------------------------------------------------ |
| 桌面资产导航 | 默认五项直接进入对应列表，详情高亮所属资产   | 收起、低高度、深色、刷新后状态                   |
| 其他         | 从侧栏右侧展开，仅显示未平铺资产，选择后关闭 | 外部点击、Escape、全部平铺后无空菜单、低高度边界 |
| 数据工具分组 | 标题与业务资产同级，数据管理入口仍可直接进入 | 收起时隐藏标题，手机布局不变                     |
| 设置 > 导航  | 开关显隐、保存、恢复默认                     | 未保存不生效、存储失败不丢原设置、受限禁用       |
| 偏好持久化   | 刷新与同源页面同步                           | 旧/损坏/重复/未知 ID、合法空配置                 |
| 移动端       | 常用资产与其他使用同一配置                   | 从其他返回、配置变化、横向溢出                   |

当前状态：本地交互原型完成，待用户验收。未修改正式代码、在线详细设计，未提交或部署。

## 验证结果

- 后续侧向展开与分组标题调整：45 项回归通过，包含资产导航 14 项、应用框架 9 项和资产操作 22 项。增加位置断言，验证收起/展开、500/600/768px 高度、打开后改变窗口尺寸以及全部资产放入“其他”；关闭按钮、外部点击、Escape 和选择跳转正常，公共筛选浮层保持原行为。
- 已对照调整前后设置页截图，检查新增“数据工具”标题与既有分组的字号、字重、行高和颜色一致；侧向面板位于侧栏外且不越出视口。手机底部面板保持原样。
- 140 项相关回归通过：导航及设置 59 项（包含本轮新增 13 项），资产相关 81 项（关联任务、业务收减、候选人等资产操作、公司联系人、AI 处理、知识图谱及岗位视觉）。
- 修复了公共设置操作区在手机上多个按钮各占 100% 导致的横向溢出，单按钮设置页保持原行为。
- 一条旧资产测试因“公司”导航和“公司”筛选器同名而定位不唯一，已限定正文区域并复验通过；未为通过测试而修改导航名称或业务操作。
- 桌面展开/收起、768px 和 600px 高度、深色其他浮层、390px 手机资产入口及返回路径、桌面和手机设置页均完成截图检查，并与原导航和设置页基线对照。导航宽度、字体、状态、主题和资产页面保持既有体系。
- 基线截图：`artifacts/asset-navigation/before/`；本轮截图：`artifacts/asset-navigation/after/`。浮层继承深色主题，相关视口无页面级横向溢出。
- 构建、修改文件 Prettier 和 `git diff --check` 通过；仍保留原有大 bundle 提示。
- 加载、读取失败、权限受限使用原型参数模拟；浏览器保存失败、损坏配置、同源页面同步为真实存储路径测试。不代表已接入账户级后端偏好。
