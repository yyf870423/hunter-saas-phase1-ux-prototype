# 官网与产品风格统一 · 决策记录

范围：官网第三版（`public/landing-origin/`，中英文）与产品原型（`src/`）。
做法参考：官网和产品共用“基础层”（logo 形状、字体、图标、组件形状），各自保留“表达层”（官网的云海、摄影、动效；产品的信息密度和中性色）。

## 已定

### 1. 明暗（2026-10-22）
- 官网默认深色，产品默认浅色（支持深色），保持不变。营销站偏暗、产品可切换明暗是业界常见做法。

### 2. 品牌色（2026-10-22）
- 官网（铂寻 Boseek）：粉紫，B5 bo 原色。logo、标签页图标、品牌氛围保持粉紫。
- 产品（HunterBuddy）：湖蓝 × 珊瑚。产品 logo、按钮、界面强调色保持湖蓝。
- 两个 logo 是同一个 bo 形状的两种配色，共用形状，不共用颜色。

### 3. 字体（2026-10-22，尚未实施）
参考：Stripe、Linear、Vercel 官网与产品共用同一无衬线家族；中文产品界面普遍用系统黑体（Element Plus、Ant Design 推荐系统字体栈）；中文品牌字体多只用于官网标题（如钉钉进步体）。

| 用途 | 官网 | 产品 |
|---|---|---|
| 正文、界面 | Inter + 苹方 / 微软雅黑 | Inter + 苹方 / 微软雅黑 |
| 标题 | DM Serif Display + 思源宋体（只打包用到的字），作为品牌表达 | 无衬线（Inter + 苹方），用字重拉开层级 |
| 衬线 | 标题 | 只在品牌时刻使用（登录页、产品名） |
| 等宽小标题 | 同一字体栈 | 同一字体栈 |

- 字体栈参考：`Inter, "Helvetica Neue", Helvetica, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", Arial, sans-serif`
- Inter 只打包实际用到的 2–3 个字重，不用整份可变字体。
- 实施时清理产品里残留的 Geist Sans、Familjen Grotesk、思源黑体引用（登录页外观不改）。

### 4. 按钮与组件（2026-10-22，尚未实施）
- 官网主按钮保持白底黑字；产品主按钮保持湖蓝。两边靠形状、圆角、字体衔接，不靠颜色。
- 官网不使用湖蓝（文字、按钮都不染湖蓝，见第 5 条）。
- 已一致、保持：8px 圆角、描边次按钮、下划线 Tab、胶囊状态标签、等宽小标题。
- 实施时对齐：图标线宽两边统一为同一个值（官网 1.6、产品 1.8，二选一）；主按钮悬停效果统一为同一种（如轻微变亮）；官网焦点框改为和产品相同的描边形式，颜色用浅色。
- 高度不必统一：官网按钮 48px、产品 36px，营销页按钮更大是常规做法。

### 5. 官网不展示产品界面（2026-10-22）
- “四件事”右侧保持官网风格的结果卡片（深色底、白字），官网上不放产品截图，也不用代码重建产品片段。
- 因此官网上完全不出现湖蓝。两边只靠 bo 形状、字体、圆角和组件形状衔接。
- 演示数据暂不统一：官网和短片用星川机器人、林越、许晴、张远，产品原型保持星澜机器人。以后如果做产品截图或演示视频，再统一。

### 6. 珊瑚的用法（2026-10-22，部分尚未实施）
- 珊瑚只在产品里使用，做小面积点缀：未读角标、新线索提示（尚未实施）。原来空状态关系网里的珊瑚流动线随第 7 条一起去掉。
- 珊瑚不表示“待确认”“需要你决定”之类的状态，避免和删除、出错用的红色混淆。产品的“待确认”继续用琥珀标签。
- 官网不使用珊瑚。官网的“待确认”继续用关系图里的粉色虚线。

### 7. 不共用标志性元素（2026-10-22，尚未实施）
- 关系网、星点、流动光点只属于官网，产品里不用。
- 产品去掉空状态里的关系网线稿，空状态只留图标、标题、一句说明和可选操作。
- 两边只靠 bo 形状、字体、圆角和组件形状衔接。等宽小标题按第 3、4 条，两边用同一字体栈，颜色各自保持现状。
- 产品的加载光带是产品自己的加载样式，保留。

## 实施清单（讨论已完成，等确认后开始）

官网（`public/landing-origin/`，中英文）

2. 按第 4 条：主按钮悬停效果、焦点框和产品对齐；图标线宽统一。

3. 字体按第 3 条：正文同上；页面标题从衬线改为无衬线，用字重拉开层级；衬线只留在登录页和产品名；清理 Geist Sans、Familjen Grotesk、思源黑体引用。
4. 等宽字体栈两边统一。
5. 按第 4 条：主按钮悬停效果、焦点框、图标线宽和官网对齐。
6. 按第 6 条：未读角标、新线索提示用珊瑚。
7. 按第 7 条：去掉空状态里的关系网线稿。
