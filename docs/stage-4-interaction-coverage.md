# 原型阶段四：交互与状态覆盖

> 状态：实现与自动化验证完成，等待人类审批。
>
> 日期：2026-08-21。

## 一、覆盖原则

1. 八类正式资产共用导航、搜索筛选、列表或卡片、详情头部、Tab、Modal、Toast、文件、来源、审核和回收站组件。
2. 页面展示的公司、联系人、岗位、候选人、招聘机会、版图、论文和专利使用同一组 Mock 身份，跨页面名称、数量和关系保持一致。
3. 反向关系只读同一事实来源；编辑从事实所有者入口完成，不在公司或版图页面创建第二份补丁数据。
4. Agent 建议、任务状态、推进阶段和正式资产状态分别展示，不混写为同一种状态。
5. 所有输入路径必须反馈新建、补充、无变化、待确认或失败，不允许静默跳过。
