# Landing Page Surface Brief

- Scope / mode：根路由 `/` 的完整营销首页；Persuade。
- Audience：中国独立猎头和资深猎头顾问；阶段一不以团队管理或企业 HR 为首要目标。
- Job：在数秒内理解 Hunter 如何围绕一个岗位跨渠道找人、统一身份与证据、形成候选池，并在联系和正式推荐前交回猎头判断。
- Primary action：拿一个岗位来演示；次级动作查看 `position-vla` 真实寻访；已有用户进入 `/home`。
- Proof：只使用当前原型已有的“具身智能 VLA 算法负责人”演示工作流和产品能力；不使用虚构商业证明。
- Direction：光学证据编舞。浅色纸面、深海军蓝与 Hunter 蓝、蓝青扫描轨道、琥珀人工判断刹停点。
- Atmosphere：大面积背景使用暖白纸面、低饱和蓝青光学冷光与极淡的人工判断琥珀反射建立空间层次；不使用纯色平铺、装饰性渐变球、满版网格或廉价玻璃感。
- Voice：像一位做过难岗位、知道人会散落在哪些渠道、也懂候选人关系分寸的资深顾问说话。先说“找不全、认不准、依据散”的真实处境，再解释 Hunter 如何召回、合并、去重和补证；尊重顾问判断，不用“颠覆、赋能、智能化”等泛化技术话术。
- Memorable moment：证据片沿轨道进入、扫描、对齐，在“需要你判断”处刹停，批准后继续离场。
- Approved comp：`.impeccable/mocks/decision/evidence-choreography-spine-theatre-v3-login.png`。
- Constraints：完整响应式、减少动态支持、无虚构客户 / 指标 / 价格 / 认证、不进入真实外部发送。
- Unresolved decisions：无。
