# 阶段七：首页与认证页面设计方向

> 状态：设计方向讨论中，未进入高保真原型。

## 一、已确认范围

1. 设计 Hunter 对外公开首页，不替换登录后的工作台。
2. 设计用户端登录、注册及必要状态。
3. 设计运营端登录；运营端不提供公开注册入口。
4. Hunter 是重 AI 的科技类招聘产品，首页必须同时体现 AI 执行能力、招聘业务价值和人工审核边界。
5. 首页需要有现代科技感，可以使用 3D 和动效，但 3D 必须表达真实业务流程，不能只是装饰粒子、光球或无业务含义的抽象动画。
6. 参考范围包括招聘科技产品、AI 产品以及知名科技公司官网。

## 二、现有产品约束

1. 登录后产品继续使用已审批的 `WorkBuddy × Vercel AI` 设计语言。
2. 对外首页可以更具传播性和空间感，但必须与产品端的字号、蓝色强调色、SVG 图标、圆角和控件语言保持可识别的继承关系。
3. 用户从首页进入登录或注册后，视觉应逐步收敛到产品端，不应像进入另一个品牌。
4. 运营端登录与用户端共用品牌基础 Token，但要明确标识 `Hunter 运营端`，并减少营销内容。

## 四、候选设计方向

### 方向 A：AI 招聘编排中枢（推荐）

- **核心概念**：把 Hunter 表达成“一位猎头指挥多个 Agent 持续完成招聘工作”的业务操作系统。
- **视觉组合**：WorkBuddy 的 Agent 工作心智 + Vercel 的空间与排版 + Metaview 的招聘业务表达 + Stripe 的页面节奏。
- **首屏 3D**：全屏空间中展示招聘目标、Agent 任务、公开证据、公司、岗位、候选人和审核节点。数据流按真实流程移动，并在人工确认节点暂停。
- **动效**：任务节点分解、证据流入、候选人聚合、审核门禁暂停、确认后写入资产；滚动时从宏观编排逐步进入真实产品界面。
- **优势**：最符合已确认的业务主线、支线任务和资产关系，也最容易与登录后的产品端衔接。
- **风险**：流程图形必须保持可读，不能演变成复杂的 3D 关系网。

### 方向 B：人才智能图谱

- **核心概念**：用人才、公司、岗位、论文、专利和关系形成可探索的智能人才网络。
- **视觉组合**：Google DeepMind 的科学可视化 + Attio 的关系数据表达 + Juicebox 的人才结果。
- **首屏 3D**：以人物与公司为主体的空间关系图，用户输入目标后，相关关系逐层显现，最终收敛为可审核候选人结果。
- **动效**：关系扩散、证据附着、身份合并、冲突提示和结果聚焦。
- **优势**：识别度强，适合表达人才摸排和跨资产探索。
- **风险**：容易让用户误以为 Hunter 的核心只是知识图谱，也可能过度承诺尚未完全确定的图谱能力。

### 方向 C：AI 人才观测站

- **核心概念**：把 Hunter 表达成持续发现招聘机会、人才变化和业务信号的 AI 观测与行动系统。
- **视觉组合**：NVIDIA / Scale AI 的可信系统感 + Raycast 的精致交互 + Vercel 的中性界面。
- **首屏 3D**：人才市场信号在空间雷达和时间轨道中出现，Hunter 聚合、分级并转化为待执行动作。
- **动效**：信号扫描、风险分层、趋势聚合、任务触发和运行状态变化。
- **优势**：科技感最强，能够突出“主动发现”而非传统 ATS。
- **风险**：容易偏监控、风控或企业情报产品，对个人猎头不够温和。

## 五、推荐结论

推荐采用 **方向 A：AI 招聘编排中枢** 作为主方向，并从方向 B 中借用少量关系探索表达。

原因：

1. Hunter 的差异化不是单点搜索，也不是单纯的资产管理，而是 Agent 驱动完整猎头业务流程。
2. 方向 A 能同时展示自然语言发起、持续执行、支线任务、人工审核和业务资产沉淀。
3. 它与已审批的产品端交互一致，不需要为官网创造另一套产品心智。
4. 3D 具有明确业务含义，后续可以降级为移动端静态或轻动效版本，不影响信息传达。

## 六、认证页面方向

### 用户端

1. 登录与注册使用统一认证外壳，品牌视觉承接首页，但减少 3D 负担，优先保证输入和状态清晰。
2. 大屏可以显示一段轻量、真实的 Hunter 工作流预览；移动端只保留品牌标识、表单和必要帮助。
3. 后续原型必须覆盖登录、注册、验证、忘记密码、账号已存在、凭据错误、网络错误、加载和禁用状态。

### 运营端

1. 使用独立入口和 `Hunter 运营端` 标识，不提供注册。
2. 页面使用更克制的同源设计，不展示营销内容或用户成果。
3. 后续原型覆盖登录失败、账号禁用、二次验证、会话失效和权限不足状态。

## 七、下一步门禁

设计方向经人类确认后，先制作三套小范围可交互 Moodboard，每套只覆盖：

1. 首页桌面首屏与移动首屏。
2. 首页一个业务流程说明区。
3. 用户登录与注册。
4. 运营端登录。
5. 3D 与动效分镜、降级策略和 `reduced-motion` 状态。

Moodboard 通过后，再编写首页信息结构和全部认证流程，最后进入完整高保真原型。
