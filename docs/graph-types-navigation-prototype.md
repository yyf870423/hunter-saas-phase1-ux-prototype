# 知识图谱类型与快捷导航

日期：2026-09-07。范围：当前 SaaS 可交互原型；本轮未修改 Hunter 正式代码、在线详细设计，未提交或部署。状态：实现与回归验证完成，待用户验收。

## 已确认范围

- 每份图谱只属于一个必填类型。“人才地图”就是原来的“组织架构”，不保留两个重复类型。
- 现有类型共八类：人才地图、公司关系、候选人关系、岗位人才、岗位知识、行业知识、技术与人才、人才流动。
- 新建、筛选、编辑、列表和详情共用类型目录及基本资料；类型不决定图页布局，也不限制内部节点、关系或图页数量。
- 卡片标题下使用公共 `TagList` 显式显示“类型：名称”，图页数量单独排列；窄屏元信息允许换行，编辑类型后标签同步更新。
- 左侧知识图谱默认显示人才地图、公司关系、候选人关系三个快捷类型，可以在“设置 > 导航”中配置。
- 导航主项 36px、子项 28px、分组间距 12px；740px 及以下桌面视口主项为 34px、分组间距 10px。默认配置在 700/720/768/900px 高度下不需要滚动，更多自选项和更矮窗口仍可滚动访问。
- 子项统一 13px、次级文字色和缩进，选中态复用公共高亮；收起导航隐藏子项，手机通过列表筛选访问，不增加底部主导航。
- Agent 用量移入用户右拉菜单，只显示已用百分比和到期日期；轻量详情同样只保留这两项，仍可进入订阅管理。示例数据沿用 64% 与 2026-08-31 到期，不代表真实账户状态。

## 组件与数据

| 层级         | 组件或文件                                                 | 职责                                          |
| ------------ | ---------------------------------------------------------- | --------------------------------------------- |
| 类型目录     | `graph-types.js`                                           | 稳定类型 ID、中文标签、默认快捷项和白名单路由 |
| 基本资料状态 | `topic-graph-store.js`                                     | 本地保存、校验、删除恢复、同源同步和排序      |
| 共享业务表单 | `GraphMetadataFields` / `GraphMetadataEditor`              | 名称、类型、说明共用字段和编辑 Modal          |
| 公共导航     | `AssetTypeNavigation`                                      | 二级入口、当前项、缩进和固定行高              |
| 导航设置     | `NavigationSettingsPage`                                   | 资产显隐与类型显隐共同保存及恢复默认          |
| 基础组件     | `FilterBar`、`SelectMenu`、`Modal`、`SettingRow`、`Toggle` | 继续使用产品级视觉、交互及主题                |

`hunter-topic-graphs-v1` 保存基本资料，`hunter-topic-graph-order` 继续保存卡片顺序。`hunter-asset-navigation-v1` 保留原资产显隐字段并增加 `graphTypeIds`；旧偏好升级时保留资产选择，新类型快捷项采用默认值。合法空数组不能误判为损坏数据。保存失败不替换当前内存状态。

类型、关键字和分页保存在 URL。进入详情或新建时通过独立 `from` 参数保留列表上下文，不与图谱内部图页参数混用；快速连续筛选使用最新参数合并，不能覆盖上一条件。

## 交互覆盖

| 操作       | 入口                   | 正常路径                             | 异常与边界                             | 状态   |
| ---------- | ---------------------- | ------------------------------------ | -------------------------------------- | ------ |
| 类型筛选   | 知识图谱列表、左侧子项 | 与搜索取交集、刷新保留、父项查看全部 | 未知类型、无匹配、分类空状态           | 已覆盖 |
| 新建       | 列表新建按钮           | 分类带入、保存后进入真实新图谱       | 名称或类型缺失、重名、保存失败重试     | 已覆盖 |
| 编辑       | 卡片菜单、详情头部     | 同一表单编辑名称、类型与说明         | 取消、未修改禁用、字段错误、保存失败   | 已覆盖 |
| 分类移动   | 编辑类型               | 原分类移出、新分类出现、详情同步     | 保留内部图页，不制造第二份图谱         | 已覆盖 |
| 列表返回   | 详情、新建返回         | 保留原关键字、分类与分页             | 更换类型后返回原分类空列表             | 已覆盖 |
| 拖拽顺序   | 图谱卡片               | 筛选内调整相对顺序、刷新保留         | 隐藏记录不丢失、存储失败恢复           | 已覆盖 |
| 删除与恢复 | 卡片删除、回收站       | 删除后从列表移除，恢复保留类型       | 恢复重名可改名、永久删除不复活示例     | 已覆盖 |
| 快捷配置   | 设置 > 导航            | 开关、保存、恢复默认、刷新同步       | 全部关闭、父入口隐藏、旧配置、保存失败 | 已覆盖 |
| 多页面同步 | 同源标签页             | 图谱资料与导航偏好同步               | 损坏数据回退、合法空配置保留           | 已覆盖 |
| 页面状态   | 列表、新建、编辑、设置 | normal、loading、empty               | error、disabled、permission-limited    | 已覆盖 |
| Agent 摘要 | 用户菜单、手机更多     | 百分比、到期日期、进入订阅页         | 关闭、Escape、小视口                   | 已覆盖 |

验证入口为 `tests/stage4/graph-types-navigation.spec.js`，包含 21 项交互、卡片类型及存储测试；公共筛选一致性补充见 `filter-controls-consistency.md`。

## 验证结果

- `PLAYWRIGHT_PORT=4177 npx playwright test --workers=5`：311 项全部通过，包含本轮 20 项知识图谱交互与 3 项跨页面筛选一致性测试。
- 卡片类型后续反馈：每张卡片标题下增加独立公共类型标签，八类、新建、编辑同步及手机不裁切验证通过；图谱专项更新为 21 项。最新全量结果见工作台迭代 `dashboard-layout-prototype.md`。
- 桌面、平板、手机及深色主题的相关页面已截图检查；导航按 700/720/768/900px 高度验证，无默认配置滚动，筛选项不相互遮挡。
- 构建、修改文件 Prettier 与 `git diff --check` 通过；仅保留原有大 bundle 提示。
- Review 修复：创建仅跳固定空页、编辑仅跳详情、快速筛选覆盖上一条件、零待确认数被错误兜底、运营质量表缺少稳定行 ID、窄屏筛选项压缩重叠。同步修正旧测试对字号、浮层挂载位置、创建禁用态和隐藏导航文字的过期断言，没有放宽业务门禁。

## 范围边界

- 本轮持久化仅覆盖图谱基本资料与导航偏好。原有画布、图页增删编辑、AI 整理、审核、版本与历史引擎仍按原型原有内存交互运行，没有新增完整画布持久化或正式升级迁移。
- 类型目录固定，不提供类型 CRUD 或多层分类；分类不改变正式资产事实。
- 保存、重名、存储失败和同源同步是实际浏览器状态路径；加载、权限受限等继续使用原型状态参数模拟。
