03 — 人和关系

查过的人和公司都存下来了，
谁和谁是什么关系，也存下来了。

刚才四件事查过的公司、岗位和人，都存下来了。谁在哪家公司待过、谁和谁一起写过论文、谁能帮你引荐谁，这些关系也都存着。资料一更新，这些关系和匹配也跟着更新，没确认的会一直标着“待确认”。

发现新岗位 公司 → 岗位 → 联系人

一家公司在扩张：先找到具体岗位，再找对口的联系人。联系不上，再请熟人引荐。

摸清团队 公司 → 人才地图 → 候选人

想摸清一家公司：按团队和关键岗位排好，把在职的人和你库里的候选人对上号。

为岗位找人 岗位 → 人才地图 → 候选人 → 论文与专利

新岗位来了：先从人才地图里的目标团队找人，再用论文和专利确认专长对得上。

为人选找机会 候选人 → 公司 → 岗位

候选人想动了：顺着他的经历和熟悉的公司，对照你手上在招的岗位。

04 — 工作方式

六步，
每件事都这样做。

不管从一条新闻、一份 JD 还是一位候选人开始，都是这六步。前四步交给 HunterBuddy，第五步留给你，第六步留给下一件事。

  1. 01HunterBuddy

    弄清要什么

    一个岗位、一家公司或一位候选人，它先理清要什么、已经知道什么、还缺什么。

    → 要什么、缺什么，一目了然
  2. 02HunterBuddy

    先翻手上的

    先从你已有的客户、做过的候选人、人才地图和人脉里找，不从零开始。

    → 手上已有的人和关系，先摆出来
  3. 03HunterBuddy

    再去外面找

    公开网络、招聘页、论文专利、开源社区和你上传的资料，一起补齐。

    → 每条线索都记着从哪来
  4. 04HunterBuddy

    核对整理

    同一个人的资料合并成一份，每个判断都写着来源，拿不准的标“待确认”。

    → 理由和来源写在一起，拿不准的单列
  5. 05你来定

    由你开口

    到这里它会停下。联系谁、什么时候开口、怎么说、推不推荐，你说了算。

    → 联系和推荐，你说了算
  6. 06HunterBuddy

    存下来接着用

    确认过的公司、人和关系都存下来，下一件事从这里接着做。

    → 下一件事不用从头来
05 — 谁做什么

找线索、对资料、写理由，交给它。
联系和推荐，你说了算。

HunterBuddy 来做
  • 发现新动向，分清哪些确定、哪些是猜测
  • 多个渠道一起找人，认出同一个人
  • 写清为什么合适、哪里有风险、还缺什么
  • 起草邮件，每封由你确认后发出
你来决定
  • 谁值得联系、先联系谁
  • 什么时候开口、怎么说
  • 要不要正式推荐、怎么跟客户承诺

资料可以交给它读，人得你来谈。HunterBuddy 能核对两份资料是不是同一个人，拿不准的单独标出来，也能把合适和不合适的理由摆在一起。但候选人的意愿、客户的关系、开口的时机和正式推荐，还得靠懂行的你。

06 — 常见问题

先把疑问说清楚，
再带一件手上的事来试。

HunterBuddy 适合谁使用？↓

独立猎头和资深顾问，尤其是同时在做 BD 和交付、手上有几个难岗位、库里攒了不少候选人的人。线索散在融资新闻、招聘页、简历库、论文和开源社区里，一个人很难天天盯着、一一读完。做过的功课会存下来，下一件事接着用。

和直接用 ChatGPT 这类 AI 搜索，有什么不同？↓

通用 AI 每次只回答一个问题，不记得你做过什么。它给的名单里，人是不是同一个、消息从哪来，还得你自己再查一遍。HunterBuddy 每次都从你手上的资源出发：熟悉的公司、做过的候选人、人才地图和能帮你引荐的人。不同地方的同一个人会先核对再合并，每个判断都写着来源。做完的事会存下来，下一次更快。

它会替我盯着市场和候选人吗？↓

可以。你可以让它定期帮你看，比如每周看一次某个赛道有没有新公司拿到融资、目标公司的招聘页有没有变化，或你关注的候选人公开履历有没有更新。只有值得你看的变化才会提醒你，重复的会合并，没有新消息就不打扰你。它不会自己动手，下一步做什么由你决定。

人选和线索从哪些渠道来？↓

已有候选人、人才地图、公开网络与招聘页、论文与专利、开源项目，以及你上传的简历和资料。每条线索都记着来自哪里。散在不同渠道里的同一个人，会先核对再合并。哪些渠道找过了、哪些还是空白，也会标出来，方便你决定下一步去哪里补。

我手上的候选人库和人才地图能带进来吗？↓

可以。简历可以单份或批量上传，Excel 等格式的人才地图可以导入后接着补。带进来的资料同样会核对身份、查重合并，也可以对你所有在招的岗位做一次匹配。

匹配结果可以直接相信吗？↓

把它当作带来源的参考，而不是最终结论。每条匹配理由都附上来源，你可以点回去看原始资料。没有可靠来源的信息会标为“待确认”，不会把猜测当成事实。像实际带多大团队、本人想不想动，这类只有聊了才知道的事，HunterBuddy 会明确留给你。
