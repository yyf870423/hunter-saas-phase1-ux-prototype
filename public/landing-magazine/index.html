04 · 谁做什么

找线索、对资料、写理由，交给它。
联系和推荐，你说了算。

资料可以交给它读，人得你来谈。HunterBuddy 能核对两份资料是不是同一个人，拿不准的单独标出来，也能把合适和不合适的理由摆在一起。但候选人的意愿、客户的关系、开口的时机和正式推荐，还得靠懂行的你。

  • 谁值得联系、先联系谁你来决定
  • 什么时候开口、怎么说你来决定
  • 要不要正式推荐、怎么跟客户承诺你来决定
能做什么

猎头每天在做的四件事，
它都能帮上忙。

做猎头不只是找人：先要发现谁在招，再摸清对方的团队，然后找到合适的人。手上的候选人想动了，还要帮他找下一个机会。下面用星川机器人这一家公司，把四件事走一遍。

人和关系

查过的人和公司都存下来了，
谁和谁是什么关系，也存下来了。

四件事查过的公司、岗位和人，都存下来了。谁在哪家公司待过、谁和谁一起写过论文、谁能帮你引荐谁，这些关系也都存着。资料一更新，这些关系和匹配也跟着更新，没确认的会一直标着“待确认”。

存下来的关系五类资料
公司在招 →岗位还在不在招，待确认
公司在职 →联系人现在负责什么，待确认
公司待过 →候选人任职时间，待核对
岗位匹配理由 →候选人条件和意向，待确认
联系人认识 →候选人能不能引荐，待确认
论文与专利作者 / 发明人 →候选人同名的人，要核对
发现新岗位公司 → 岗位 → 联系人

一家公司在扩张：先找到具体岗位，再找对口的联系人。联系不上，再请熟人引荐。

摸清团队公司 → 人才地图 → 候选人

想摸清一家公司：按团队和关键岗位排好，把在职的人和你库里的候选人对上号。

为岗位找人岗位 → 人才地图 → 候选人 → 论文与专利

新岗位来了：先从人才地图里的目标团队找人，再用论文和专利确认专长对得上。

为人选找机会候选人 → 公司 → 岗位

候选人想动了：顺着他的经历和熟悉的公司，对照你手上在招的岗位。
