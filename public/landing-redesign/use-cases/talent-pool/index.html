核心能力 07 · 沉淀

人才库：
一人一档，随时间更新

人才库是一项把同一个人在不同平台的身份、履历和沟通记录合并成一份档案的能力，它自动查重、追踪变化，并把每次沟通沉淀到同一条时间线。

人才库贵的不是存储，是失真。库里躺着同一个人的三份简历和两个花名，谁也不知道哪一份是最新的。

铂寻 Boseek·更新于 2026-11-21

01

人才库为什么会越用越旧？

  • 同一个人，在库里可能有多个名字

    脉脉昵称、GitHub ID、英文名、中文名各不相同。资料分散在不同平台，无法确认是不是同一人，重复记录越积越多。

  • 从峰会、论文和社区找到的人，只有一条线索

    公开报道和会议嘉宾往往只有姓名、公司和方向。要判断这个人值不值得跟进，还得继续补全教育背景、项目、论文和联系方式。

  • 简历没变，人可能已经换了公司

    资料停在入库那天。是还在原公司、属于哪个事业部、职级有没有变化，靠人工很难跟踪。拿旧资料去推荐，轻则失准，重则推错人。

  • 公司发生大事，库里的人没有被激活

    融资、组织调整、业务收缩、新实验室成立，都会影响人才流动。这些信息通常只停在新闻里，没有和库内的人建立联系。

  • 最有价值的沟通信息，散在 Excel、录音和聊天记录里

    候选人现在公司的真实情况、期权和年终发放方式、离职原因、看机会的顾虑，往往最有价值，也最难查找。

02

HunterBuddy 怎么运维人才库？

  1. 一人一档：先识别，再合并

    系统根据公司、教育经历、工作履历和技能方向，判断几份简历是否属于同一个人。它支持合并、拆分和撤销，并保留原始资料与合并历史。

  2. 从一条短线索，补成一份可读档案

    峰会嘉宾或论文作者只有一条信息时，系统补全内容并生成待审核建议，每条都保留来源。它不直接覆盖原资料，冲突部分单独提示确认。

  3. 持续复核变化，不等候选人自己更新简历

    系统按关注的人选、目标公司或技术方向持续查看公开信息，发现公司、团队和职位变化。变化作为更新信号呈现，不推断求职意愿。

  4. 把公司情报和库内人才连起来

    目标公司出现融资、裁员、组织调整或负责人变动时，系统提取相关人员和团队信息，与库内人才交叉匹配，标出“建议复核”。

  5. 把沟通记录沉淀到同一条时间线

    每次沟通后，把公司情况、薪酬结构、离职原因、机会偏好和下次跟进时间记在同一条档案里。换岗位之后，这些记录仍然可用。

边界

HunterBuddy 不把同名当同人，不从拼音猜中文名，也不把公开变化直接当成求职意愿。
